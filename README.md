# 🛡 FestaCMS — Bot Blocker

> Плагин блокировки ботов, сканеров и плохих IP для FestaCMS.

[![Version](https://img.shields.io/badge/version-1.0.0-blue.svg)](CHANGELOG.md)
[![License](https://img.shields.io/badge/license-MIT-green.svg)](LICENSE)
[![PHP](https://img.shields.io/badge/php-%3E%3D%207.4-8892BF.svg)](https://php.net)

Плагин блокирует доступ к сайту для нежелательных ботов, сканеров уязвимостей, SEO-краулеров и плохих IP-адресов. Полностью настраивается через админку FestaCMS: правила, пресеты, логи, импорт/экспорт.

---

## ✨ Возможности

- 🚫 **Блокировка по IP** — один адрес или CIDR-диапазон
- 🕵️ **Блокировка по User-Agent** — для известных ботов и сканеров
- 🔗 **Блокировка по Referer** — для спам-сайтов
- ✅ **Белый список** — для своих IP и доверенных ботов (Google, Яндекс)
- 📝 **Лог срабатываний** — кто, когда, откуда
- 🎯 **Пресеты** — готовые наборы правил (SQL-инъекции, сканеры CMS, SEO-краулеры)
- 📥 **Импорт/экспорт** — в CSV и JSON
- 🔄 **Автообновление** — через GitHub Releases
- ⚙️ **Настройки** — что отдавать при блокировке (403 / 404 / редирект)

## 📦 Установка

### Через админку FestaCMS

1. Зайдите в админку: `https://ваш-сайт.ru/pan268189/`
2. Откройте раздел **Плагины**
3. Найдите **Bot Blocker** в списке
4. Нажмите **Установить**
5. Плагин активируется автоматически

### Вручную

1. Скачайте последний релиз из [GitHub Releases](../../releases)
2. Распакуйте архив в папку `/pan268189/plugins/bot-blocker/`
3. Запустите установщик: `https://ваш-сайт.ru/pan268189/plugins/bot-blocker/install.php`
4. В админке → Плагины → активируйте **Bot Blocker**

## ⚙️ Использование

### Добавление правил

1. Админка → **Плагины** → **Bot Blocker**
2. Вкладка **Правила**
3. Нажмите **Добавить правило**
4. Выберите:
   - **Тип:** IP / CIDR / User-Agent / Referer
   - **Значение:** что искать
   - **Действие:** Заблокировать / Разрешить / Только логировать
   - **Комментарий:** для памяти
5. Сохраните

### Пресеты

Вкладка **Пресеты** — готовые наборы правил. Включаются в один клик:

- 🤖 Известные сканеры уязвимостей
- 🔍 SEO-краулеры (Semrush, Ahrefs, MJ12 и др.)
- 📁 Сканеры чужих CMS (WordPress, Joomla, DLE)

### Лог

Вкладка **Лог** — все срабатывания с фильтрами по дате, IP, правилу.

## 📋 Требования

- **FestaCMS** — версия **1.0.0** или выше
- **PHP** — версия **7.4** или выше
- **MySQL** — версия **5.7** или выше
- Права на запись в папку плагина (для кеша)

---

## 🔒 Безопасность

- Плагин **не имеет доступа** к данным пользователей сайта
- Все правила валидируются перед сохранением
- IP и User-Agent фильтруются от инъекций
- Логи не содержат чувствительных данных
- Свой IP админа **автоматически** попадает в белый список
